# Blood cell detection with YOLO26

Detection of red blood cells, white blood cells and platelets in peripheral
blood smear images. Trained on the BCCD dataset with YOLO26s.

Test set: mAP50 0.863 · mAP50-95 0.605

**Research and educational use only. Not a diagnostic device.**
